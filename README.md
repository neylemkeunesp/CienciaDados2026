## 🌟 Sobre o Curso (Edição 2026)

Esta versão foi completamente reformulada e modernizada para acompanhar o estado da arte do ecossistema de dados e inteligência computacional em **2026**.

A disciplina adota o princípio de **separação de responsabilidades**:
1. **Teoria e Conceitos em Lâminas LaTeX (Beamer)**: Todo o embasamento teórico, evolução histórica, formulações matemáticas, arquitetura de sistemas e princípios analíticos estão organizados em apresentações profissionais em formato widescreen (16:9).
2. **Prática Hands-On em Jupyter Notebooks (Material Básico)**: Cada aula possui um caderno prático enxuto, direto e limpo de distrações, focado exclusivamente no essencial: código Python 3.12+ executável, análise exploratória e exercícios graduados de fixação.

## 🚀 Como Configurar o Ambiente Local

### Pré-requisitos
- Python 3.11+ instalado (recomendado: Python 3.12)
- Gerenciador de pacotes [uv](https://docs.astral.sh/uv/) (ou `pip` padrão)

### Instalação Rápida com `uv` (Recomendado):
```bash
# Clone o repositório
git clone https://github.com/neylemkeunesp/CienciaDados2026.git
cd CienciaDados2026

# Crie o ambiente virtual e instale todas as dependências
uv venv
source .venv/bin/activate
uv pip install -e .

# Inicie o JupyterLab
jupyter lab
```

### Instalação com `pip` tradicional:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

## 🛠️ Compilação das Lâminas LaTeX (Beamer)

Todas as lâminas utilizam o tema institucional moderno definido em `slides/style/beamer_theme_cienciadados2026.sty`. Para compilar todas as apresentações de uma vez:

```bash
bash scripts/compile_all_slides.sh
```

Os PDFs gerados são automaticamente sincronizados na pasta `pdf_slides/`.
