2. Paradigma Imperativo vs Funcional

Vamos calcular a soma dos quadrados dos números pares de 1 a 10 de duas formas.

code · célula 6
# Abordagem 1: Imperativa (instruindo o passo a passo com mutação de estado)
soma_imperativa = 0
for x in range(1, 11):
    if x % 2 == 0:
        soma_imperativa += x ** 2

print(f'Soma imperativa: {soma_imperativa}')
code · célula 7
# Abordagem 2: Funcional (composição de funções puras e imutabilidade)
pares = filter(lambda x: x % 2 == 0, range(1, 11))
quadrados = map(lambda x: x ** 2, pares)
soma_funcional = sum(quadrados)

print(f'Soma funcional: {soma_funcional}')

1. As Quatro Coleções Nativas de Python

  • Lista (list): ordenada, mutável, permite duplicatas.
  • Tupla (tuple): ordenada, imutável (ideal para registros fixos).
  • Conjunto (set): não-ordenado, mutável, elementos únicos (busca rápida $O(1)$).
  • Dicionário (dict): pares chave-valor, chaves únicas.
code · célula 3
idades = [21, 25, 21, 30, 25, 19, 21]

# Deduplicação instantânea com set
idades_unicas = set(idades)

def estatisticas_basicas(valores: list[float]) -> dict[str, float]:
    """
    Calcula média, mínimo e máximo de uma lista numérica.
    """
    if not valores:
        raise ValueError('A lista não pode estar vazia.')

    return {
        'media': sum(valores) / len(valores),
        'minimo': min(valores),
        'maximo': max(valores)
    }

print(estatisticas_basicas([10.5, 20.0, 15.2, 33.1]))

def converte_para_float(lista: list[str]) -> list[float]:
    validos = []
    for item in lista:
        try:
            validos.append(float(item))
        except ValueError:
            continue
    return validos

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_squared_error

# Carregando dados
df = pd.read_csv('Automobile price data.csv')
df['price'] = pd.to_numeric(df['price'], errors='coerce')
df['horsepower'] = pd.to_numeric(df['horsepower'], errors='coerce')
df_reg = df.dropna(subset=['price', 'horsepower'])

X = df_reg[['horsepower']]

print(f'Intercepto: {modelo.intercept_:.2f}')
print(f'R² Score: {r2_score(y, y_pred):.3f}')
